# Настройка прокси — 17 октября 2026

Все публичные прокси удалены. В `kufar-proxies.txt` и `.env.example` остался только `socks5h://127.0.0.1:1080`.

На Linux-сервере контейнер использует сеть хоста (`network_mode: host`), чтобы обращаться к SOCKS-сервису на `127.0.0.1:1080`. Этот сервис нужно запустить отдельно на сервере.

Команда `git pull --ff-only && bash update.sh --local-proxy` сохраняет копию `.env`, удаляет прежний основной адрес и настройки пула, устанавливает локальный SOCKS5h-прокси и отключает резервные маршруты. Настройки Telegram, пользователи, поиски и история сохраняются.

Прокси применяется к API Kufar. Telegram через `KUFAR_PROXY` не направляется. Проверка TLS остаётся включённой. Доступность SOCKS-сервиса и Kufar на сервере проверяет скрипт обновления после запуска контейнера; с этого компьютера серверный прокси не проверялся.
